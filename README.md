## Apa itu LayerUp?

LayerUp membantu streamer game (saat ini Mobile Legends) mengatur live tanpa repot pindah-pindah aplikasi:

- **Skor dan rank otomatis**: Victory, Defeat, streak, win rate, dan bintang rank yang naik turun sendiri.
- **Antrian mabar**: penonton dapat token dari gift TikTok, follow, atau donasi Saweria, lalu antre lewat chat `!mabar`.
- **Komen album dan review profil**: antrean terpisah lewat `!album` dan `!review`.
- **Alert**: ucapan terima kasih gift, follow, share, dan Saweria, lengkap dengan gambar gift.
- **Overlay**: scoreboard, banner, rank, teks info, antrean, dan alert. Tinggal tempel link ke TikTok LIVE Studio.
- **Aplikasi Windows**: koneksi TikTok, shortcut keyboard yang bisa diatur sendiri, dan jendela kontrol kecil yang selalu di atas game.

## Cara mulai

1. Daftar dan login di [versi web](https://layer-up-liart.vercel.app).
2. Unduh dan pasang **LayerUp-Setup.exe**, lalu login dengan akun yang sama.
3. Isi username TikTok di menu Koneksi, tempel link overlay ke TikTok LIVE Studio, lalu mulai live.

Aplikasi memperbarui dirinya sendiri: versi baru diunduh di latar dan terpasang saat aplikasi dimulai ulang.

## Kalau Windows memblokir

Aplikasi ini belum ditandatangani sertifikat, jadi Windows bisa menahannya saat pertama dibuka:

- **"Windows protected your PC"** (layar biru): klik **More info**, lalu **Run anyway**.
- **Smart App Control** memblokir tanpa pilihan: pakai **versi portable**, atau matikan Smart App Control di Windows Security > App & browser control.

## Kebutuhan

- Windows 10 atau 11 (64-bit)
- Akun TikTok yang bisa live dan TikTok LIVE Studio

## Catatan

- Koneksi ke TikTok memakai pustaka komunitas (tidak resmi), jadi sesekali bisa terganggu kalau TikTok mengubah sistemnya.
- Kode sumber LayerUp tidak dibuka. Repo ini hanya berisi file unduhan.
